# Учёт складских товаров

Учебный проект для учёта товаров на небольшом складе.

## Цель
Создать основу системы, которая помогает хранить сведения о товарах, отслеживать остатки и фиксировать поступления и списания.

## Основные возможности (план)
- каталог товаров: артикул, название, категория, цена;
- просмотр текущего остатка;
- регистрация поступления и списания;
- предупреждение о низком остатке;
- поиск товара по артикулу или названию.

## Структура проекта
- `project-notes.md` — описание задачи и требования;
- `api-plan.md` — предварительный план API;
- `git-conflict.md` — описание учебного Git-конфликта.

## Статус
Сейчас подготовлена документация и структура будущего приложения. Реализация бизнес-логики запланирована на следующие этапы.

## Пример сценария
1. Кладовщик добавляет товар с артикулом `P-100`.
2. Регистрирует поступление 40 единиц.
3. После продажи 8 единиц оформляет списание.
4. Система показывает остаток 32 единицы.
