# Предварительный план API

Базовый префикс: `/api/v1`.

## Товары
- `GET /products` — получить список товаров;
- `GET /products/{id}` — получить один товар;
- `POST /products` — добавить товар;
- `PATCH /products/{id}` — изменить данные товара.

## Складские операции
- `POST /stock/receipts` — зарегистрировать поступление;
- `POST /stock/write-offs` — зарегистрировать списание;
- `GET /stock/movements` — посмотреть историю движений.

## Пример товара
```json
{
  "sku": "P-100",
  "name": "Бумага A4",
  "category": "Канцелярия",
  "quantity": 40,
  "unit_price": 5.50
}
```

## Проверки
- артикул обязателен и уникален;
- количество в операции должно быть положительным;
- списание нельзя провести, если остатка недостаточно.
