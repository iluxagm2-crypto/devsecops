# История Git

В проекте использованы ветки:
- `main` — основная версия документации;
- `feature/product-catalog` — поля карточки товара;
- `feature/stock-alert` — предупреждение о низком остатке;
- `feature/stock-report` — отчёт по остаткам.

В `main` выполнены слияния функций предупреждения, отчёта и каталога. При слиянии `feature/stock-report` возник конфликт в `project-notes.md`, потому что обе ветки меняли одну и ту же строку. Конфликт разрешён вручную с сохранением обеих идей.
