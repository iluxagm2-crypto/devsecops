# Заметки по проекту: учёт складских товаров

## Проблема
При ручном учёте легко потерять информацию о количестве товаров, поступлениях и списаниях.

## Цель проекта
Подготовить простую систему, в которой можно вести каталог товаров и контролировать складские остатки.

## Пользователи
- кладовщик — регистрирует поступления и списания;
- менеджер — просматривает каталог и остатки.

## Данные товара
- `id` — уникальный идентификатор;
- `sku` — артикул;
- `name` — название;
- `category` — категория;
- `quantity` — количество на складе;
- `unit_price` — цена за единицу.

## Правила учёта
1. Артикул товара должен быть уникальным.
2. Количество не может быть отрицательным.
3. Поступление увеличивает остаток.
4. Списание уменьшает остаток.
5. Операция должна сохранять дату и тип движения.

## Ближайшие этапы
1. Спроектировать API.
2. Добавить хранение товаров.
3. Реализовать операции движения товара.
4. Добавить проверку минимального остатка.

## Минимальный запас
Система должна показывать текущий остаток, формировать отчёт по количеству каждой позиции и предупреждать кладовщика, когда запас достигает минимального порога.
